# 老人端图片与 3D 动效设计意图单

用途：老年用户在电脑或手机浏览器中使用，首页以办理、提醒和语音为短路径，保持单列阅读。
承诺：这页只让人记住“点选需要的服务，就能看到怎么办”。
纸：纯白。养老服务需要清楚的照片、文字和操作边界，纯白能直接呈现真实内容，不借纹理制造氛围。
色：中性灰阶 + 墨绿 #075C46 + 朱橙 #9C3125；墨绿只用于主操作和当前态，朱橙只用于提醒和错误路径。
主角：首屏社区照护照片框架是唯一会动的对象，入场后静止；服务入口、提醒、工单和资源不增加装饰动画。
词：① 透视 perspective + 层移 translateZ（册 2，3D 纵深轴）；② 入场编排 choreography（册 10，时间轴与停顿轴）。
参数：透视 600–1200px 中选 900px；层差 20–60px 中选 24–40px；入场 420–700ms 中选约 560ms；缓动使用 cubic-bezier(.22,1,.36,1)；无持续循环、无过冲。
图片：选择真实社区照护或老人生活照片，本地下载并压缩，保留来源与许可记录；不使用与内容无关的图库拼图。
适老约束：非衬线字体，必要文字至少 16px，标题行距 1.3、正文 1.5–1.8，核心文本对比度至少 4.5:1，重要元素不用蓝紫，主要热区至少 60×60px，整卡可点，点击优先，保留语音与文字多模态。
验收：桌面和 390px 手机无横向溢出；主要热区至少 64×64px；首屏动画结束后读数稳定；prefers-reduced-motion 下无动画并显示无倾斜静态终态；图片加载失败时文字和办理入口完整可用；家属、社区、登录页及既有业务回归通过。
实现：原生 HTML + CSS 3D，不引入 Three.js 或动画框架；只增加一张本地图片、老人端作用域样式和必要的静态结构。
