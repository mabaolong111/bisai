# 设计意图单

> 开工前填完这一页，才能动笔写代码。它不激发创意，它的作用是**限量**——不填，结果一定是"每册各取一个堆在首页"。

---

## 模板（复制这七行，逐行填）

```
用途：给谁看 / 在哪看 / 大概多长（几屏）
承诺：这页只让人记住一件事——（一句，不超过 20 字）
纸：从六张里选一张（网格 / 走线 / 坐标 / 暗场 / 纸感 / 纯白），并写"它为什么能解释这个题材"
色：中性灰阶 + 强调色（≤2 个），强调色只允许出现在（数据 / 当前态 / 路径）中的哪一类
主角：全页只有一个会动的东西是（　），其余保持 settle
词：≤3 类，查 words.md 后填（词 + 册号 + 轴）
验收：读哪几个数 / 移动端怎么算过 / reduced-motion 停在哪个终态
```

---

## 填写示例（作品集长页）

```
用途：招聘方在浏览器里看 3 屏，先扫再停
承诺：这是一个"会算数据的人"，不是"会做动效的人"
纸：网格（4 的倍数可见），因为它要证明排版是算过的，不是感觉
色：灰阶 #15181A→#C7CBC6，强调色 1 个（赭 #B23A2A），只用于数据与当前进度
主角：右侧那条随进度生长的折线（12 §04 弧长参数化）
词：① 滚动进度映射（7）② 弧长参数化（12）③ 卡片堆叠（8）—— 只三类
验收：进度读数 0–100%、移动端 390px 无横向溢出、reduced-motion 停在 50% 静态
```

---

## 三条判定（任一条不成立就退回重填）

1. **"主角"超过一个 → 退回。** 一屏两个会动的元素，等于没有主角。
2. **"词"超过三类 → 退回。** 三类是上限，不是建议值。
3. **"纸"解释不通 → 退回。** 写不出"它为什么能解释这个题材"，这张纸就是贴上去的。

---

## 反例（照这样填一定会翻车）

- 承诺写"高级、有质感、国际化"——三个形容词，等于没说；
- 色写"主色蓝，辅色紫，点缀青"——三个强调色，风格立刻散；
- 词写"全部册子里的动效都用一点"——这是最常见的死法；
- 验收写"看着舒服"——不可复核，等于没有验收。
